# ISO

ISO is a connected AI workspace for teams. It brings tools, company knowledge, channels, permissions, and hosted agents into one managed experience.

[View the live site](https://iso-sepia.vercel.app/)

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is generated in `dist`.

## Stack

- React 19
- TypeScript
- Vite
- Motion
- Phosphor Icons
- Native CSS

## Current status

The marketing site and its interactive product previews are implemented. The early-access form currently demonstrates the interface state and does not store submissions.
